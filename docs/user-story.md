
# User Story: Task Management

## Description

As a user,
I want to create, view, update and delete tasks,
so that I can manage my daily activities.

## Task Fields

- ID
- Title
- Description
- Status

## Expected Features

1. Create a task.
2. View all tasks.
3. View a task by ID.
4. Update an existing task.
5. Delete an existing task.

## Scope

Implement happy-path functionality only.

No authentication, notifications, multi-user support
or complex business rules.
